Host a server

Runs a Menhir relay on this computer, published as a Tor onion service. Keep the app running to keep your server online.

⚠ Tor is required — and it isn't installed

Your server is published as a Tor onion service. Without Tor it would only exist on this computer, which is useless for chatting with other people.

macOS  brew install tor

Linux  sudo apt install tor

Install it, then press Check again — you don't have to configure anything, Menhir runs Tor for you.
